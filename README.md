# Channel — lk2nd

Standalone lk2nd bootloader build for the Motorola Moto G7 Play.

## Build

Run **Build lk2nd MSM8953** in GitHub Actions.

Source: [msm8916-mainline/lk2nd](https://github.com/msm8916-mainline/lk2nd), release `23.1`; target `lk2nd-msm8953`.

## Artifact

`channel-lk2nd-msm8953` contains `lk2nd-msm8953.img`, the source revision and checksums.

This workflow builds only lk2nd.
