# Channel — DTBO

Standalone DTBO build for the Motorola Moto G7 Play.

## Build

Run **Build channel DTBO** in GitHub Actions.

Source: [barni2000/dtbo-lk2nd](https://github.com/barni2000/dtbo-lk2nd).

## Artifact

`channel-dtbo` contains `dtbo-motorola-channel.img`, the source revision and checksums.

This workflow builds only the DTBO image.
